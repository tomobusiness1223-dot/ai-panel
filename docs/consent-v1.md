# 回答の利用目的と個人情報の取り扱い（同意文 v1 ・下書き）

登録画面の「同意する」チェックの横に「全文を読む」を置き、開くとこの文が出ます。法務確認前の下書きです。

## この調査について

この調査は、ChatGPT などの AI が、人によってどんな商品やサービスをおすすめするかを調べるものです。あなたが AI に質問して得た回答を、ほかの参加者の回答と合わせて集計し、企業向けの調査レポートとして利用します。

## お預かりする情報

- 登録時に入力いただく情報（性別、生まれた年、お住まいの都道府県、同居家族、ChatGPT の利用状況など）
- お題ごとに提出いただく AI との会話の共有リンクと、その会話の内容（AI からの質問、あなたの答え、AI の回答、AI が参照したウェブページ）
- いま使っているブランドと、買い替え予定の有無
- LINE のユーザー ID（お題の案内やポイントの管理に使います）

氏名、電話番号、メールアドレス、住所は収集しません。会話の中にこれらが含まれていた場合は、保存する前に伏せ字にします。

## 利用目的

1. 属性別に「どのブランドが、何位で、どんな理由で推薦されるか」を集計し、企業向けの調査レポートとして提供すること
2. お題の案内、提出の受付、ポイントの付与と交換のご連絡
3. 調査の仕組みの改善（読み取りの精度向上、質問文の見直しなど）

## 企業に提供する範囲

企業には、人数で集計した結果と、個人を特定できない形に加工した会話の抜粋だけを提供します。あなたの LINE の ID、登録情報そのもの、会話の全文は提供しません。

## 保存と削除

- 会話の内容は、名前などを伏せたものを分析に使い、原文は暗号化して [要決定：90日] 保存したのち削除します。
- 参加をやめたいときは、LINE で「退会」と送っていただくか、[問い合わせ先] までご連絡ください。登録情報と未集計の回答を削除します。集計済みの結果からは個人を取り出せないため、削除できません。

## ポイントについて

提出1件につき、お題に表示されたポイントを付与します。受付できなかった提出（共有リンクが開けない、質問文が変更されているなど）には付与されません。ポイントの交換先と最低交換額は [要決定]。ポイントの付与条件と交換先は、事前のお知らせのうえで変更することがあります。

## 注意事項

- 共有リンクを作ると、その会話は URL を知っている人なら誰でも閲覧できる状態になります。他人に見られたくない内容を含む会話は提出しないでください。
- 提出後に会話を削除しても、受付時に保存した内容は上記の期間、保持されます。
- ChatGPT のメモリ機能が ON の場合、AI はあなたの過去の会話をもとに回答することがあります。それ自体がこの調査の対象です。OFF にする必要はありません。
